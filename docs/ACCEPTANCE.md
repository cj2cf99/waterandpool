# 验收表：真实水体 ≥ 90%

用户要求：必须靠近真实水体，至少 9 成完成度，达不到就持续迭代。
"真实"无法由我主观说了算，所以拆成下面可检查的项目。**阈值一旦写下不放宽**（只允许增加项目）；每次评分都附证据（测试输出或截图路径）。

总分 100 = A 物理 40 + B 视觉 40 + C 交互与性能 10 + D 工程 10。**≥ 90 才算完成。**
A、C 项为脚本测试，客观；B 项为我对照截图自评，主观，评分要保守，并在报告里写明。

## A 物理（8 项 × 5 分，`node tools/test-physics.mjs`）
| 编号 | 检查 | 满分条件 | 零分条件 |
|---|---|---|---|
| A1 | 静水平衡：含干湿交界的粗糙海床，静水 20 秒 | 最大流速 < 1e-6 m/s | ≥ 1e-3 |
| A2 | 质量守恒：封闭域内造浪+上冲 | 体积相对误差 < 1e-9 | ≥ 1e-4 |
| A3 | 长波波速：深 0.8m 水槽小振幅波 | 与 √(gh) 误差 ≤ 3% | ≥ 10% |
| A4 | 上冲高度：Synolakis 1:19.85 斜坡孤立波（H/d=0.0185）上冲 R | 与 R/d = 2.831·√(cotβ)·(H/d)^1.25 误差 ≤ 15% | ≥ 50% |
| A5 | 风应力壅水：封闭浅水槽稳定风，水面坡度 | 与 τ/(ρ g h) 误差 ≤ 10% | ≥ 50% |
| A6 | 造浪精度与开边界反射：平水槽 | 波高误差 ≤ 10% 且反射系数 < 0.10 | 误差 ≥ 40% 或反射 ≥ 0.4 |
| A7 | 船：静态吃水与阿基米德一致（≤3%）、垂荡周期与理论一致（≤10%）、静水+强风船不动（风不直接作用于船） | 三项全过 | 任一项严重不符 |
| A8 | 综合稳定与交互：风暴 10 分钟模拟无 NaN、h≥0；浪撞石头产生水花事件，静水无；岸边有上冲/回流与湿沙记忆 | 全过 | 出现 NaN 或负水深 |
分段给分：满分条件给 5 分，零分条件给 0 分，中间线性插值。

## B 视觉（10 项 × 4 分，`node tools/capture.mjs` 截图自评，证据放 `out/`）
每项 0–4：4 = 与真实清水/海滩照片的典型特征一致且无明显伪影；3 = 特征齐全但细节偏弱；2 = 有但粗糙；1 = 勉强可见；0 = 没有。
| 编号 | 检查（真实清澈水体的典型特征） |
|---|---|
| B1 | 透明度：浅处能清楚看到沙底与石头，深处按 Beer–Lambert 渐变为青绿，红光先被吸收 |
| B2 | 折射：水下沙底/船体随波面扭曲（不是贴图透明），扭曲随波浪变化 |
| B3 | 菲涅尔：掠射角以天空反射为主，俯视角几乎透明；太阳高光为拉长的闪烁亮点 |
| B4 | 焦散：水下沙底有随波移动的亮线网络，浅处强、深处淡 |
| B5 | 波形：不同风速的波高/波长/陡度符合量级，浪向与风向一致，近岸变陡、破碎 |
| B6 | 风的痕迹：阵风斑块在水面移动、涟漪有方向性、强风出现白浪（whitecaps） |
| B7 | 岸边：浪舌上冲薄水层、回流、湿沙变深色并缓慢变干、泡沫花边 |
| B8 | 石头拍浪：撞击处水花喷起（粒子）、泡沫环、回落溅点 |
| B9 | 船：木质细节与吃水线、随波俯仰横滚升沉、船边小波纹/尾迹、锚绳 |
| B10 | 整体画面：天空与光照、色调映射、抗锯齿，无拉伸/闪烁/接缝/穿帮 |
