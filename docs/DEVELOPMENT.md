# 开发说明

## 结构
- `src/swe.js` 求解器；`src/terrain.js` 地形与石头；`src/waves.js` 造波/风浪谱；`src/boat.js` 船；`src/sim.js` 仿真主类（泡沫、水花、耦合）。
- `src/render/` WebGL2 渲染（阴影、焦散、平面反射、水体、泡沫、泛光）；`src/main.js` UI；`src/worker.js` 仿真线程。
- `tools/` 测试、截图、开发服务器；`?capture` 模式主线程手动步进，供无头截图。

## 已知局限（如实记录）
- 水面为高度场：不会卷浪翻卷，破碎只用泡沫/粒子近似。
- 浅水方程无频散；涌浪周期限制在 2.4–3.7 s 以保持近似可用。
- 船的附加质量系数为假定值，未用势流计算；船体对水的反作用以压力项近似。
- 风速→涌浪参数为经验公式，风浪细节（Gerstner）仅在着色器中，不参与船的受力。
- B 项（视觉）为保守自评，非客观测量；证据截图在 `out/`。
- 沙丘偏荒漠、无植被，石头偏锥形，水花偏小，是后续可改进点。
- 软渲染（SwiftShader）下测过；真实 GPU 上帧率未实测。
